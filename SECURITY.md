# Security

The console is an administrative interface. Source editing grants the ability
to change server code after restart. Use individual administrative credentials,
HTTPS for network access, and a dedicated OS account. Do not expose the console
to ordinary business-API users. Keep local robot safety controls independent
of remote web orders.

Report suspected vulnerabilities privately to mike.jung.global@gmail.com.
Include the version and a minimal reproduction without real passwords, keys,
robot addresses or customer data. Do not include secrets in public issues.
This address is a reporting channel; no response-time SLA is promised.

The project does not claim a formal security audit, complete secret detection,
or hard real-time robot safety certification. See docs/CONSOLE_FILES_LOGS_KO.md
for precise editor and log limits.
